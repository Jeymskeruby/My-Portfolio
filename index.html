About

Full-stack, across the stack — and across platforms.

I'm a full-stack developer who has shipped commissioned software on three very different stacks: a Laravel 13 + Inertia/React + Filament admin console backed by PostgreSQL and WebSockets; a Firebase (Firestore + Auth) web app; and a .NET 8 VB.NET desktop application. Each was a real multi-role system with a real client.

What ties the portfolio together is what I did next with each one.

Three commissioned, multi-role dashboard systems — each rebuilt as a safe, self-contained public demo. Mock or local backend, deterministic fictional data, no client data or credentials, one-click role login, and a "Reset Demo Data" button. Open any of them below and click around; nothing talks to a server.
